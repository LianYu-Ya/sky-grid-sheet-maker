# sky-grid-sheet-maker

一款用于制作《光遇》（Sky: Children of the Light）**格子谱**的桌面编辑器。
以 3×5 键位小网格为最小单元，用旋律色 / 和弦色块标记按键，支持键盘输入、鼠标点选、分页导出 PNG，轻松排版成经典的块状格子谱。

基于 **Python + PySide6（Qt for Python）**，纯本地运行，数据与导出文件都保存在本应用文件夹内。

---

## 功能特性

- **块状格子谱编辑**：每节拍 = 一个 3×5 键位小网格，按"每横排 X 个"换行排列；小格边长随窗口宽度自适应缩放并居中
- **双色标记**：主旋律与和弦用两种颜色区分（颜色可自定义），同一节拍可放多个键
- **格子谱样式**：6 种边框样式（默认 / 完整内外边框 / 无外边框 / 无边框纯色块 / 粗内线 / 粗内线+外框），非默认样式采用连续贯通格线（线宽均匀、交点不叠加变粗）；可自定义旋律 / 和弦 / 背景 / 边框四色，样式与颜色随乐谱保存、打开自动还原
- **多路输入**：
  - 键盘输入 `YUIOPHJKL;NM,./`（普通键=主旋律，Shift+键=和弦，不自动前进）
  - 格子谱左键=主旋律切换、右键=和弦切换、中键=只切光标
  - 键位面板点击同样支持左键 / 右键
- **自动跳转**：可开启按节奏自动换拍（从本拍第一个键计时，阈值可调，步进 50ms）
- **便捷编辑**：方向键移动光标（末尾自动追加空白拍）、Backspace 清空当前拍、Del 删除当前拍
- **键位面板**：图形（菱形中带圆 / 菱形 / 圆形）随键位类型区分；可切换键面显示：字母 / 按键编号（1–7 循环，高音带点）/ 音调（C D E F G A B…）/ 空白
- **导出预览 + 分页导出**：导出前预览每一页，可调每页行数 / 列数；默认分层模式输出到 `outputs/<乐谱名>/`（也可平铺直出）；多页文件自动命名为 `xxx_1.png`、`xxx_2.png`；文件名与图片上显示的乐谱名相互独立；预览对话框内可临时调整样式与颜色（仅本次导出生效，不写回乐谱）
- **乐谱管理**：保存 / 浏览 / 复制 / 重命名 / 删除 `.ggp` 源文件（默认存于应用目录下 `sheets` 文件夹），浏览窗口可定位文件所在位置
- **导出 PNG 长图**：可带标题（乐谱名），未填写则不绘制
- **可换行工具栏**：控件始终显示，放不下自动换行，不出现溢出收起按钮

## 运行环境

- Windows（开发与测试环境）
- Python 3.10+
- 依赖：`PySide6`

## 快速开始

```bash
pip install -r requirements.txt
python main.py
```

或直接双击 `启动.bat`（自动检测 Python、自动安装 PySide6 后启动）。

不想装环境？直接下载现成的 Windows 打包版：[v1.0.0 Release](https://github.com/LianYu-Ya/sky-grid-sheet-maker/releases/tag/v1.0.0)（解压即用，已含 `sheets/` 与 `outputs/` 目录）。

## 操作说明

| 操作 | 效果 |
| --- | --- |
| 左键点击格子谱 / 键位面板 | 切换主旋律标记 |
| 右键点击 | 切换和弦标记 |
| 中键点击格子谱 | 只切换光标位置 |
| 键盘 `YUIOPHJKL;NM,./` | 输入主旋律（不前进光标） |
| `Shift` + 键盘按键 | 输入和弦 |
| `←` / `→` | 移动光标（末尾右移自动追加空白拍） |
| `Backspace` | 清空当前拍全部音符 |
| `Del` | 删除当前拍（整拍移除，后续左移） |
| 工具栏「自动跳转」 | 开启后按节奏自动换拍（阈值可调） |
| 工具栏「格子样式」 | 切换格子谱边框样式（6 种） |
| 工具栏「样式颜色」 | 自定义旋律 / 和弦 / 背景 / 边框颜色（随乐谱保存） |
| 工具栏「按键区」 | 打开设置：键面显示模式 / 显示隐藏 |
| 工具栏「导出 PNG」 | 预览并分页导出（可临时调整样式与颜色） |
| 工具栏「输出文件夹」 | 打开默认导出目录 |

## 目录说明

```
├── main.py            应用入口（简约白色主题）
├── main_window.py     主窗口（工具栏 / 格子谱区 / 键位面板 / 状态栏）

└── outputs/           PNG 导出目录（运行时自动创建）
```

## 文件格式（.ggp）

JSON 格式（version 2），可手动查看 / 编辑：

```json
{
  "version": 2,
  "title": "标题",
  "columns_per_line": 4,
  "note_grid": [[{"k": "Y", "c": false}], []],
  "grid_style": "default",
  "mark_color": "#E84848",
  "chord_color": "#4A90D9",
  "bg_color": "#FFFFFF",
  "border_color": "#B8B8B8"
}
```

- `k`：键字母（YUIOPHJKL;NM,./）
- `c`：是否和弦
- `grid_style`：格子样式（default / full_frame / no_outer / no_border / thick_inner / thick_frame，总是写入）
- `bg_color` / `border_color`：背景色 / 边框色（与默认不同才写入）
- 兼容 version 1（`[列][行]` 单字母）旧格式；旧文件缺省样式字段时自动回退默认
