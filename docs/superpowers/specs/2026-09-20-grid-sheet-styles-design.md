# 格子谱样式（Grid Sheet Styles）设计文档

- 日期：2026-09-20
- 项目：SkyGridSheetMaker 光遇格子谱制作器
- 状态：已获用户批准（方案 A + 导出对话框临时调整）

## 目标

为格子谱提供多种可切换的网格样式（边框形态）与颜色自定义能力：
- 样式随乐谱 `.ggp` 文件保存，打开时自动还原；
- 显示区（SheetWidget）与导出 PNG 使用同一套样式渲染；
- 导出预览对话框中可临时调整样式/颜色，仅作用于本次导出，不改动乐谱保存的样式。

## 样式定义（6 种）

下拉框选项（`grid_style` 枚举值 → 显示名）：

| 枚举值 | 显示名 | 渲染 |
| --- | --- | --- |
| `default` | 默认（现状） | 白底、细内线（1px，色 #B8B8B8）、无外框 |
| `full_frame` | 完整内外边框 | 每个节拍块四周有外框 + 内部细格线（1px） |
| `no_outer` | 无外边框 | 只保留内部细格线，不画外框 |
| `no_border` | 无边框纯色块 | 不画任何线条，有标记=填色，无标记=底色 |
| `thick_inner` | 粗内线 | 内部格线加粗（2px），无外框 |
| `thick_frame` | 粗内线+外框 | 内部粗线（2px）+ 节拍块外框 |

- 外框：围绕每个节拍块（3×5 键位网格）的矩形边框，线宽与内线一致（细=1px、粗=2px）。
- 无边框样式下仍保留块间距与换行布局，仅不绘制线条。

## 颜色自定义（4 色）

样式颜色对话框提供 4 个颜色按钮，点击取色并实时预览：

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| 旋律色 | `#E84848` | 主旋律标记填充（已有字段 `mark_color`） |
| 和弦色 | `#4A90D9` | 和弦标记填充（已有字段 `chord_color`） |
| 背景色 | `#FFFFFF` | 谱面底色（新字段 `bg_color`） |
| 边框色 | `#B8B8B8` | 格线/外框颜色（新字段 `border_color`） |

## 持久化（.ggp，兼容旧文件）

- 新增可选字段：`grid_style`（字符串，**总是写入**）、`bg_color`、`border_color`（**与默认不同才写入**，沿用现有 mark_color/chord_color 的"未传颜色时省略"约定）。
- 加载时缺省回退：`grid_style` 缺失 → `default`；`bg_color` 缺失 → `#FFFFFF`；`border_color` 缺失 → `#B8B8B8`；非法值同样回退默认。
- v1 旧格式加载后按默认样式处理；保存统一升级为 v2。

## UI

- 主窗口工具栏：新增「格子样式」下拉框（6 项）+「样式颜色」按钮（打开颜色对话框）。
- 修改样式/颜色后，显示区实时刷新；对应字段进入乐谱保存与脏标记逻辑。
- 导出预览对话框（ExportDialog）：
  - 新增同款「格子样式」下拉框与 4 个颜色按钮；
  - 默认填入当前乐谱的样式/颜色；
  - 用户在此处的修改**只用于本次导出**，关闭对话框不写回乐谱、不置脏。

## 渲染实现

- 新建样式模型（model.py 内或独立模块）：`GridStyle`（style_type + bg/border/mark/chord 四色）与样式选项表、默认值、合法值校验。
- `sheet_widget.py`：按 GridStyle 绘制——背景色填充、按样式决定是否画内线/外框及其线宽；选中态/光标绘制逻辑保持不变。
- `export.py`：`render_page_image` / `_draw_sheet` 接受 GridStyle（或等价参数），与显示区渲染规则一致（同色、同线宽、同外框规则）。
- 导出默认沿用当前乐谱样式；ExportDialog 中的临时改动覆盖导出参数。

## 错误处理

- 非法/未知 `grid_style`、非法颜色：一律回退默认值（与现有 `_valid_qcolor` 行为一致）。
- 保存/加载不因新字段破坏旧文件。

## 测试

- 全量回归（200 项）保持绿。
- 新增 T32 系列：
  - 各样式渲染像素断言（外框存在/不存在、内线粗细、无边框无线条、背景色/边框色生效）；
  - 下拉框切换联动显示区与导出；
  - 样式/颜色随 .ggp 往返保存一致；
  - 旧文件（无样式字段）加载回退默认；
  - 导出对话框临时修改不影响乐谱保存值。
